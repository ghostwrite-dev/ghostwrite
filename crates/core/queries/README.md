# Queries

`textobjects/` holds what `maf`, `mia`, `]f` and the other syntax text objects select, a
tree-sitter query for each language. They're helix's (`runtime/queries/*/textobjects.scm` at
https://github.com/helix-editor/helix), with the files each inherits from put in it, and as such
are under the Mozilla Public License 2.0 (https://mozilla.org/MPL/2.0/), unlike the rest of
Ghostwrite.
