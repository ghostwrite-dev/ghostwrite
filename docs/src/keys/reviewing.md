# Reviewing

While a story is up the editor is in AI mode, in whichever view has the keys. These keys decide; the motions still look around. See [Asking and reviewing](../stories/reviewing.md).

| Keys | What they do |
| --- | --- |
| `tab` | accept the step · next note or match (in any view); with a step waiting elsewhere, go back to it first |
| `tab` | a command: run it in the terminal, and on |
| `enter`, `space a` | redirect, or ask about it |
| `esc` `esc` | stop, back where you were; what you accepted stays |
| motions | look around; no editing |

When the model asks to read something outside the project, `tab` lets it and `enter` doesn't.
