# Editing

Ghostwrite's keys are helix's, as helix has them. If you know helix, you know Ghostwrite: Ghostwrite's own keys are under `space`, and ⌘ is for the app (tabs, windows, files).

If you come from Vim, the main difference is the order: you select first, then act. `w` selects to the next word, and `d` deletes what's selected. The selection is always visible, so you see what a key will act on before you press it.

This chapter covers:

- [Modes and views](modes.md): normal, insert, select and AI, the same in every view: the code, Files, the terminal, a tab of pages, and what's beside a file.
- [Moving and jumping](moving.md): motions, counts, the jump list.
- [Selecting and text objects](selecting.md): selections, `mi` and `ma`, the syntax tree.
- [Multiple cursors](cursors.md).
- [Changing text](changing.md): editing, registers, `.` and macros.
- [Searching](searching.md): in the file and across the project.
- [Files, tabs and panes](files.md): pickers, the file tree, tabs, splits.

The [key reference](../keys/README.md) lists every key, section by section, as `space ?` shows them.
